Q1: In OOP, what do we call the characteristics of an object?
A1: Attributes (or member fields).

A2: Methods (or member subroutines).

EXERCISE 4
--------------------------------------------------------------------
Q1: What happens when we execute the code of example 4?
A1: It prints the exact same sentence twice ("Hello, my name is Speed and i am 1 year(s) old."); the age stays 1.

Q2: Why does this happen?
A2: The __age attribute is private (starts with __), so Python applies name mangling (_Cat__age). Direct modification (cat1.__age = ...) fails to update the actual private attribute.

Q3: It's cat1's birthday. What is the correct way to change its age? Display cat1's age after his birthday.
A3: Use the public method birthday() and the getter getAge():
cat1.birthday()
print(cat1.getAge())

Q1: Write your Prompt:
A1: "Explain Python namespace packages, how they differ from regular packages with __init__.py, and give a short example."

Q2: Synthesize the answer with your words:
A2: A namespace package groups sub-packages or modules spread across different directories under one parent package name without needing an __init__.py file.

Q3: Now, explain why it is useful?
A3: It organizes code across multiple files for better readability and maintenance, avoids naming conflicts, and simplifies code reuse.
